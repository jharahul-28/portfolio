## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## Build

```bash
npm run build
npm start
```

## Deployment

Deployable on [Vercel](https://vercel.com) with zero configuration — connect the GitHub repo and deploy.
